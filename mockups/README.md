# Макеты Storm Trip

Статические HTML-макеты интерфейса планировщика поездок. Никакой сборки не нужно —
откройте `index.html` в браузере и переходите по ссылкам в шапке или кнопкам.

## Экраны

| Файл | Что показывает |
|---|---|
| `index.html` | Поиск: естественный запрос → чипы разобранного интента (правятся вручную), структурная форма, панель источников |
| `results.html` | Результаты: карточки комбинаций (транспорт + событие + отель + прогулка), скоринг, теги, статусы источников |
| `trip.html` | План поездки: таймлайн по дням, бюджет, карта, источники, .ics |
| `walk.html` | Прогулка: карта с точками и пешим маршрутом, список мест с временем, темп, категории |

`style.css` — общий стиль всех экранов. Иконки — инлайновый SVG-спрайт в каждой странице,
внешних зависимостей и шрифтов из сети нет, работает офлайн с `file://`.

## Что макеты отражают из архитектуры

- **Интент виден пользователю**: разбор текста показывается чипами — ошибки правил исправляются вручную.
- **Прозрачность источников**: каждая панель «Источники» повторяет контракт `SourceResult`
  (`SUCCESS / EMPTY / FAILED`).
- **Комбинация — в ядре**: карточки результатов показывают состав комбинации и скоринг
  (прямой рейс, зазор до события, рейтинг отеля).
- **Прогулка встроена в план**, а не отдельная сущность: маршрут вписан в свободное окно таймлайна.

Подробности — в `docs/architecture.md`.
